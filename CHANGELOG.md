## 0.1.0

Initial implementation, before release automation was in place. See the specification in `openspec/specs/`.

### Features

- MCP server exposing the WHMCS Admin API over stdio and Streamable HTTP.
- All 162 documented WHMCS actions reachable; 15 to 25 tools advertised
  depending on the profile.
- Capability profiles (`readonly`, `support`, `billing`, `admin`), read-only by
  default.
- Prepare/confirm protocol for consequential operations, with tokens bound to
  the exact arguments, expiring and single-use.
- Allowlist projection, secret and PII redaction, untrusted-content envelopes
  for customer-authored text.
- Bounded I/O: request timeouts, response size cap, clamped pagination, retries
  restricted to read-classified actions.
- Audit stream with per-operation IDs correlating confirmation issuance and
  consumption.
- Action registry generated from the vendor documentation, with hand-maintained
  safety classification and a generation-time gate on unclassified actions.
